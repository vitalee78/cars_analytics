**Cars Analytics**

```Пайплайн сбора, обработки и аналитики данных по автомобильным аукционам```

**Описание**

Проект предназначен для ETL-обработки данных с автомобильных аукционов: 
очистка, трансформация и загрузка данных в аналитические хранилища для последующего анализа и построения отчётов.

**Технологии**

| Компонент       | Стек                    |
|-----------------|-------------------------|
| Язык            | Python 3.9+             |
| Оркестрация     | Apache Airflow          |
| БД              | PostgreSQL / ClickHouse |
| Трансформация   | dbt                     |
| Контейнеризация | Docker                        |

**Структура проекта**

```
cars_analytics/
├── dags/                     # DAG'и для Airflow
│   ├── cars_cleanup_tables.py    # Очистка временных/промежуточных таблиц
│   └── cars_auctons.py         # Извлечение сырых данных с аукционов
│   └── cars_stat.py         # Извлечение сырых данных статистики
├── scripts/cars_analytics/   # Бизнес-логика и утилиты
│   ├── dbt_cars_analytics # Расчёт минимальных цен аукционов
│   └── parsers # Парсеры для сбора данных
│   └── orm # Методы CRUD
├── tests/                    # Тесты (pytest)
├── requirements.txt          # Зависимости Python
└── README.md
```
**Основные процессы**

1. Сбор данных: парсинг/загрузка сырых данных с аукционов
2. Очистка: удаление дубликатов, валидация полей, обработка NULL
3. Трансформация: агрегация, расчёт метрик (мин. цена, статистика)
4. Загрузка: запись в fact-/mart-схемы PostgreSQL
